# 전고점 돌파 확률 발굴기

과거 데이터로 "전고점 근처까지 올라온 뒤 실제로 돌파했는가"를 학습해,
지금 전고점 근처에 있는 종목의 돌파 확률을 추정하고 **60% 이상**인 종목만 골라냅니다.

## 설치 / 실행

```bash
pip install -r requirements.txt
python breakout_finder.py                 # 한국 대표 60여 종목, 60% 기준
python breakout_finder.py --market us     # 미국 대표 종목
python breakout_finder.py --tickers 005930.KS 000660.KS 247540.KQ
python breakout_finder.py --universe-file universe.txt --min-prob 0.65
python breakout_finder.py --csv-dir ./ohlcv   # 오프라인 CSV (Date,Open,High,Low,Close,Volume)
```

`universe.txt` 형식: 한 줄에 `티커,이름` (이름 생략 가능). 코스피 `.KS`, 코스닥 `.KQ`.

## 작동 방식

1. **전고점**: 최근 5일을 제외한 120거래일 최고가 (`--lookback`).
2. **접근 이벤트**: 종가가 전고점 아래 5% 이내 (`--near`).
3. **라벨**: 이벤트 후 20거래일 안에 고가가 전고점을 넘으면 돌파 성공 (`--horizon`, `--margin`).
4. **모델**: 전 종목 이벤트를 모아 로지스틱 회귀 학습 (numpy 구현, L2 정규화).
   피처는 전고점 이격, 거래량 비율, RSI, 이평선 위치·기울기, 변동성, 최근 60일 고점 터치 횟수, 고점 경과일, 20/60일 수익률 등 15개.
5. **검증**: 시간순 앞 70% 학습 → 뒤 30% 검증. AUC, 캘리브레이션, "예측 60% 이상 구간의 실제 돌파율"을 출력합니다.
6. **종합 확률**: 모델 확률 70% + 종목별 과거 돌파 기저율(표본 수로 수축) 30%.
7. 결과는 화면 출력 + `breakout_candidates.csv/json` 저장.

## 주요 옵션

| 옵션 | 기본 | 설명 |
|---|---|---|
| `--min-prob` | 0.60 | 발굴 기준 확률 |
| `--lookback` | 120 | 전고점 산정 거래일 |
| `--horizon` | 20 | 돌파 판정 거래일 |
| `--near` | 0.05 | 전고점 근접 기준 (5%) |
| `--margin` | 0.0 | 전고점 대비 추가 상승 요구 비율 |
| `--period` | 5y | yfinance 다운로드 기간 |

## 주의

과거 통계 기반 추정이며 투자 권유가 아닙니다. 출력되는 검증 AUC와
캘리브레이션(예측 확률 vs 실제 돌파율)이 나쁘면 확률을 신뢰하지 마세요.

# 날마다 3종목 · 2~3일 전고점 돌파 테스트 (`daily_top3_test.py`)

실존 매매기법과 **30여 개 지표**로 매일 상위 3종목을 고르고, **2~3거래일 안에 전고점을 돌파했는지**를
과거 전 구간에서 하루씩 검증합니다. t일 종가까지의 정보로만 고르고 t+1일에 진입하므로 미래 데이터를 쓰지 않습니다.
지표 설명은 [INDICATORS.md](INDICATORS.md).

## 파일

| 파일 | 역할 |
|---|---|
| `indicators.py` | 전고점, 30여 개 지표, 돌파 라벨, 매매 시뮬레이션(손절·익절·비용) |
| `flows.py` | KRX 외국인·기관 순매수, 공매도 잔고 (pykrx, CSV 캐시) |
| `daily_top3_test.py` | 전략 점수, 워크포워드 ML, 백테스트, 지표 리포트, 오늘의 3종목, 저널 |

## 전략

| 전략 | 내용 |
|---|---|
| minervini | 트렌드 템플릿 + VCP·스퀴즈 |
| oneil | RS 등급·RS선 신고가 + 거래량 매집 |
| wyckoff | OBV·CMF·MFI·포켓피벗 매집 + 변동성 수축 |
| darvas | 좁은 박스 상단 |
| squeeze | TTM 스퀴즈, NR7, ATR 수축 |
| supply | 위쪽 매물대, 고점앵커 VWAP, 윗꼬리 |
| theme | 주도 테마·신기술 모멘텀 (`THEMES`에서 수정) |
| flows | 외국인·기관 순매수, 공매도 잔고 감소 (수급 데이터 있을 때) |
| combo | 위 요소 혼합 |
| **ml** | 모든 지표로 로지스틱 회귀를 **과거 데이터로만** 20일마다 재학습. 예측 확률이 `--min-prob`(기본 60%) 이상인 종목만, 최대 3개 매수 |

시장 필터: 유니버스 지수가 20일선 아래이거나 50일선 위 종목이 40% 미만이면 그날은 매매하지 않습니다 (`--no-regime`로 해제).

## 매매 규칙 (시간 고정)

- **일봉 모드(기본)**: 다음 날 시가(09:00 동시호가) 매수 → 전고점×(1+`--take-profit`) 도달 시 매도, 진입가−ATR×`--stop-atr` 이탈 시 손절, 둘 다 없으면 N일째 종가(15:20 동시호가) 매도. 같은 날 손절과 익절이 둘 다 닿으면 보수적으로 손절 처리합니다.
- 시가가 이미 전고점 위에서 시작하면(갭 돌파) 추격 매수하지 않습니다. 돌파율에는 포함되고 손익에서는 빠집니다.
- **60분봉 모드(`--intraday`)**: 종목별 평균 거래량이 가장 큰 시간대를 찾아 그 봉에서 매수·매도합니다. 야후 60분봉은 최근 730일만 제공됩니다.
- 왕복 비용 기본 0.25% (수수료, 거래세, 슬리피지).

## 실행

```bash
pip install -r requirements.txt
python daily_top3_test.py                              # 전 전략 + ML 비교, 3일 판정
python daily_top3_test.py --days 2 --take-profit 0.03  # 2일 판정, 전고점 +3% 익절
python daily_top3_test.py --strategy ml --min-prob 0.65
KRX_ID=아이디 KRX_PW=비번 python daily_top3_test.py --flows   # 외국인·기관 수급 포함
python daily_top3_test.py --intraday --days 2          # 거래량 최대 시간대 매매
python daily_top3_test.py --journal picks.csv          # 오늘 3종목 기록 + 지난 픽 자동 채점
```

## 출력 읽는 법

| 열 | 뜻 |
|---|---|
| 판정% / 95%구간 | N일 내 돌파율과 신뢰구간 |
| 기준% / 초과%p / p값 | 같은 날 후보 전체의 돌파율, 전략이 더한 값, 우연일 확률 |
| ≥2/3일% | 하루 3종목 중 2개 이상 돌파한 날 비율 |
| 평균손익% / 승률% / 손익비PF | 비용 뺀 실제 매매 결과. PF 1 미만이면 돌파율이 높아도 손해 |
| 손절% / 갭% | 손절로 끝난 비율, 갭 돌파로 매매 안 한 비율 |

이어서 **지표별 돌파 예측력**(순위상관 IC, 상위·하위 20% 돌파율)과 **ML 확률 캘리브레이션**(예측 60~70%일 때 실제 몇 %였나)이 나옵니다.

**주의할 점.** 전고점 돌파율이 높아도 돈을 번다는 뜻은 아닙니다. 전고점 바로 아래에서 사서 전고점에 팔면 수익폭이 작아, 손절 한 번에 여러 번의 수익이 사라질 수 있습니다. `평균손익%`와 `손익비PF`를 함께 보고 `--take-profit`, `--stop-atr`를 조정하세요.

## 매일 자동 실행 (본인 PC)

```bash
# crontab -e  (평일 16:10, 장 마감 후)
10 16 * * 1-5 cd /path/to/tools/stock-breakout && python daily_top3_test.py --strategy ml --journal picks.csv >> daily.log 2>&1
```

백테스트는 현재 상장 종목만 쓰므로 상장폐지 종목이 빠진 생존편향이 있습니다. 결과는 미래 수익을 보장하지 않습니다.

# 장기 매집 흔적 분석기 (`accumulation.py`)

거래는 적지만 누군가 **가격선을 지키며 주기적으로 사 모으는** 종목을 찾습니다.
종목 하나를 5년 단위로 해부하거나, 시장 전체를 스캔해 순위를 냅니다.

## 보는 흔적

| 흔적 | 계산 |
|---|---|
| 가격선 방어 | 60일 바닥선 근처까지 밀린 날 중 종가가 지켜진 비율, 바닥선 이탈 빈도 |
| 바닥 계단상승 | 바닥선이 해마다 올라가는가 |
| 거래량 비대칭 | 오른 날 거래량 ÷ 내린 날 거래량, 내릴 때 거래량이 마르는가 |
| OBV·AD 상승 | 가격과 무관하게 누적 거래량선이 오르는가 |
| 주기적 매수 | 평소 3배 이상 거래량이 터진 날의 간격과 규칙성. 이후 가격이 유지되면 흡수형, 윗꼬리·급락이면 털기형 |
| 종가 관리 | 장중 범위 상단에서 마감한 날의 비율 |
| 투자자 수급 | 외국인·기관·연기금·투신·사모·금융투자·기타법인·개인 누적 순매수와 순매수한 달의 비율 (`--flows`) |
| 내부자 매수 | 임원·주요주주 소유보고 증감 (DART 오픈API 키 또는 `--insider-csv`) |

이 흔적들을 합쳐 0~100점 **매집점수**를 냅니다. 털기형 급증이 많으면 감점합니다.

## 실행

```bash
# 서남, 동서 5년 분석 (연도별 표 + 차트 PNG + CSV)
python accumulation.py 294630 026960 --insider-csv insider_seed.csv

# KRX 수급과 DART 내부자 보고까지 포함 (둘 다 무료 가입)
KRX_ID=아이디 KRX_PW=비번 DART_API_KEY=키 python accumulation.py 294630 026960 --flows

# 전 종목 스캔: 일평균 거래대금 1~50억 종목 중 최근 1년 매집점수 순위
python accumulation.py --scan-all --min-value 1 --max-value 50
```

`insider_seed.csv`는 뉴스로 확인한 서남·동서의 내부자 매매 몇 건을 담은 시작용 파일입니다. DART 키가 있으면 DART 데이터를 쓰는 편이 정확합니다.
결과는 `accumulation_reports/` 폴더에 저장됩니다.

매집 흔적은 정황일 뿐 세력의 존재를 증명하지 않습니다. 오너 일가의 승계 목적 매수처럼, 사는 쪽이 주가가 낮기를 바라는 경우도 있습니다.
