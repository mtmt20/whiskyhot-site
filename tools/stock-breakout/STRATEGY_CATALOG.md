# 투자법 카탈로그

학술 연구와 실무에서 보고된 투자법 72가지를 모아 **한국 시장 근거**로 등급을 매긴 목록입니다.
실험실(`lab.py`)에 어떤 순서로 넣을지 정하는 기준표로 씁니다.

## 등급 기준

| 등급 | 뜻 |
|---|---|
| **A** | 해외 다수 연구 + 한국 연구에서도 확인 |
| **B** | 해외 근거가 강하지만 한국 근거가 없거나 부족. 실험실 검증 필요 |
| **C** | 한국에서 약하거나 혼재, 또는 실무 경험 위주 |
| **X** | 한국에서 반대로 작동하거나 손실. **피할 신호**로 사용 |

인지도: 개인투자자에게 얼마나 알려졌는지 (높음·중간·낮음). 낮을수록 아직 덜 붐빌 가능성이 있습니다.
실험실: `있음` 이미 구현, `쉬움` 공시·일봉만 있으면 됨, `보통` 수집 코드 추가, `어려움` 유료·비정형 데이터 필요.

> 먼저 알아둘 것. 미국 이상현상 452개를 재검증한 연구(Hou·Xue·Zhang 2020)에서 상당수가 재현되지 않았고,
> 논문 발표 뒤 수익이 평균 3분의 1가량 줄었다는 연구(McLean·Pontiff 2016)도 있습니다. 등급이 높아도 실험실 검증 구간 성적이 최종 기준입니다.

### 조합 추천

서로 다른 이유로 먹히는 방법을 섞어야 한 방법이 안 먹히는 시기를 버틸 수 있습니다.

1. **이벤트 + 가격 확인**: 실적 드리프트(32) 또는 내부자 매수(37)가 나온 종목 중 52주 신고가 근접(2)만 매수.
2. **품질 바구니**: 수익성(21) 상위 + 저고유변동성(17) + 순주식발행 감소(27), 월 1회 교체.
3. **단기 반전 + 필터**: 단기 급락(1) 종목 중 200일선 위, 공매도 집중(53) 아님, 복권형(18) 아님.
4. **달력 이벤트**: 코스피200 편입 예상(38)은 발표 전후 매수, 편입일 전 전량 매도.
