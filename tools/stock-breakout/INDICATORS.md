# 지표 사전

`daily_top3_test.py`가 쓰는 지표 전체입니다. ★ 표시는 개인 투자자에게 덜 알려졌지만 전고점 돌파 판단에 특히 쓸모 있는 지표입니다.
실행할 때마다 출력되는 **지표별 돌파 예측력** 표(`indicator_report.csv`)에서 내 유니버스에 실제로 먹히는 지표를 확인하세요.

## 1. 전고점 자체

| 지표 | 뜻 | 좋은 방향 |
|---|---|---|
| 전고점 이격 | 전고점까지 남은 거리 | 가까울수록 |
| 전고점 경과일 | 전고점이 며칠 전인가 | 오래될수록 매물이 소화됨 |
| 전고점 근접 횟수 | 최근 60일간 전고점 5% 이내에 머문 날 | 많을수록 저항 소화 |
| ★ 위쪽 매물대 비중 | 최근 1년 거래량 중 현재가~전고점 가격대에서 거래된 비중. 본전 매도 대기 물량 | 낮을수록 |
| ★ 고점앵커 VWAP 대비 | 전고점 날부터 계산한 거래량가중평균가 대비 현재가. 고점 이후 산 사람들의 평균 손익 | 양수일수록 |
| 윗꼬리 비율 | 최근 5일 캔들 윗꼬리 비중. 위에서 파는 세력 흔적 | 낮을수록 |

## 2. 추세

| 지표 | 뜻 |
|---|---|
| 미너비니 트렌드템플릿 | 50·150·200일선 정배열, 200일선 상승, 52주 고점 25% 이내, 저점 대비 +30% |
| ★ 52주 신고가 근접도 | 현재가 ÷ 52주 고점. 신고가 근처 종목이 계속 오르는 현상은 학계에서도 검증된 이상현상(George & Hwang, 2004) |
| 20일 이격도 | 종가 ÷ 20일선. 너무 크면 과열 |
| ★ ADX / DMI | 추세의 **강도**. ADX 20 이상이고 +DI가 -DI 위면 상승 추세가 살아있음 |
| 일목균형표 | 구름대 위, 전환선>기준선, 후행스팬 위, 선행스팬 양운 4개 조건 |

## 3. 상대강도

| 지표 | 뜻 |
|---|---|
| RS 상대강도 | 3·6·9·12개월 수익률 가중합의 순위 (O'Neil RS 등급) |
| ★ RS선 신고가 근접 | 주가 ÷ 시장지수 선이 1년 신고가 근처인가. **주가보다 RS선이 먼저 신고가**를 찍으면 주도주 신호 |
| 20일 수익률 | 단기 모멘텀 |

## 4. 변동성 수축 (돌파 직전 에너지 응축)

| 지표 | 뜻 |
|---|---|
| 변동성 수축비 | 10일 변동성 ÷ 50일 변동성 (VCP) |
| 10일 레인지 폭 | 최근 10일 고저 폭 |
| 거래량 고갈 | 5일 거래량 ÷ 50일 거래량. 매도 물량이 말랐다는 뜻 |
| ★ TTM 스퀴즈 | 볼린저밴드가 켈트너채널 안으로 들어간 상태. 풀릴 때 큰 움직임이 나옴 |
| 볼린저밴드폭 백분위 | 최근 120일 중 밴드폭이 얼마나 좁은가 |
| ★ NR7 | 오늘 고저 폭이 최근 7일 중 가장 좁음 (Toby Crabel). 다음 날 변동성 확대 경향 |
| ATR 수축 | 14일 ATR ÷ 60일 평균 ATR |

## 5. 매집 (가격·거래량으로 본 세력 흔적)

| 지표 | 뜻 |
|---|---|
| 상승/하락 거래량비 | 50일간 오른 날 거래량 ÷ 내린 날 거래량. 1.5 이상이면 매집 |
| OBV 기울기 | 누적 거래량 흐름 |
| ★ OBV 매집 다이버전스 | 가격은 횡보하는데 OBV만 오름. Wyckoff 매집 국면의 전형 |
| ★ OBV 선행 신고가 | OBV가 먼저 신고가를 찍음 |
| CMF (차이킨 자금흐름) | 종가가 고가 쪽에서 끝나는 날의 거래량 비중 |
| MFI (자금흐름지수) | 거래량을 넣은 RSI |
| ★ 엘더 포스인덱스 | 가격 변화 × 거래량의 13일 평균. 매수 힘의 크기 |
| ★ 포켓피벗 | 최근 10일 하락일 최대 거래량보다 많은 거래량으로 오른 날 (Kacher & Morales) |
| 대량거래 양봉 | 평균 3배 이상 거래량 양봉. 기관 진입 흔적 |
| 종가 위치(CLV) | 캔들 안에서 종가가 위쪽에 마감하는 경향 |

## 6. 투자자 수급 (한국 전용, `--flows`)

진짜 "매집세력"을 직접 보는 지표입니다. KRX에서 받아오며 `KRX_ID`, `KRX_PW` 환경변수(data.krx.co.kr 무료 회원)가 필요합니다.

| 지표 | 뜻 |
|---|---|
| ★ 외국인+기관 순매수 강도 | 20일 순매수 금액 ÷ 20일 거래대금 |
| ★ 외국인 연속 순매수 | 외국인이 며칠 연속 사고 있나 |
| ★ 공매도잔고 감소 | 20일간 공매도 잔고 비중 감소폭. 숏커버링은 돌파 연료 |

## 7. 테마·시장

| 지표 | 뜻 |
|---|---|
| 테마 강도 | 소속 테마(AI반도체, 2차전지, 방산 등)의 20일 수익률 순위 |
| ★ 시장 폭 | 유니버스 중 50일선 위 종목 비율. 40% 아래면 돌파 실패가 잦아 매매 중단 |

## 아직 넣지 않은 것

- **실적·펀더멘털** (CAN SLIM의 C·A: 분기 EPS 증가율, 실적 서프라이즈). 무료 일별 데이터가 없어 제외했습니다.
- **신용잔고, 프로그램 매매, 창구(증권사별) 매매**. KRX·증권사 API가 필요합니다.
- **뉴스·공시 이벤트**. DART API로 확장할 수 있습니다.
