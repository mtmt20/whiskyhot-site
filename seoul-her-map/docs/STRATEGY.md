# 首尔她地图 운영 전략 (v1, 2026-09)

## 1. 한 줄 목표
12개월 안에 팔로워 5만, 월 200만원 이상의 협찬·제휴 수익. 얼굴 노출 없음, 월 고정비 3만원 이하.

## 2. 포지셔닝
- 계정 정체성: "서울에 사는 여자 친구가 골라주는 진짜 가는 곳". 정보 계정이 아니라 안목(审美) 계정.
- 차별점 세 가지
  1. 김포공항 노선(상하이 훙차오·베이징 다싱·타이베이 쑹산) 이용자에게 "落地第一站" 마곡 코스. 아무도 안 하는 자리.
  2. 모든 노트에 동선 카드 + 避雷 한 줄. 저장(收藏)을 유도하는 구조.
  3. 톤: 한국식 여백과 톤다운 팔레트에 중국식 훅·스티커를 얹은 일관된 카드. 피드 전체가 한 잡지처럼 보이게.
- IP 속지가 "韩国"으로 표시되는 것 자체가 신뢰 자산. 프로필 소개에 "在首尔生活的第N年"을 명시.

## 3. 타깃 페르소나
- 26~34세 중국 1·2선 도시 여성. 직장인, 연 1~2회 해외여행, 한국 방문 경험 0~1회.
- 검색 습관: 여행 2~4주 전 "首尔 攻略", "圣水洞 咖啡", "弘大 买手店"으로 노트를 저장해 두고 현지에서 꺼내 봄.
- 원하는 것: 실패 없는 선택(避雷), 사진 잘 나오는 곳(出片), 줄 안 서는 시간(时段), 人均 가격.

## 4. 콘텐츠 기둥과 비율 (주 5회)
| 기둥 | 비율 | 포맷 | 역할 |
|---|---|---|---|
| 동네 攻略 (성수·연남·홍대·마곡 순환) | 2회 | 카루셀 7~9장 | 저장·검색 유입의 뼈대 |
| 단일 장소 探店 | 1회 | 카루셀 5장 또는 15초 영상 | 협찬 대상 매장에 보여줄 샘플 |
| 뷰티·쇼핑 (올리브영·편집샵·가격 비교) | 1회 | 카루셀 6장 | 蒲公英 뷰티 협찬 연결 |
| 실용 정보 (교통·예약·택스리펀·환전) | 1회 | 카루셀 4~5장 | 저장률 최상, 팔로우 전환 |

- 시리즈로 묶어 合集(컬렉션)에 넣는다: 「落地第一站」「圣水半日」「延南慢走」「弘大夜」「首尔实用」.
- 영상은 3개월차부터. 이미지 노트로 먼저 안목을 증명하는 게 비용 대비 효율이 높다.

## 5. 얼굴 없는 제작 파이프라인
- 촬영: 주 1회 반나절, 한 동네 4~6곳. 아이폰 + 세로 3:4 고정. 손·뒷모습·소품·음료·간판·창가 빛. 얼굴 없이도 "사람이 다녀온 느낌"은 손과 테이블 컷으로 만든다.
- 보정: 한 프리셋 고정(웜 크림, 채도 -10, 그레인 약간). 피드 통일이 곧 브랜드.
- 생성: places.csv 입력 → `npm run note` → 카드 PNG·본문·태그·대본 자동 출력 → 사람이 문장 다듬기 10분.
- 캐릭터: 라인 드로잉 마스코트 1장. 프로필과 커버 구석에만. 영상은 나레이션만(Edge TTS 晓晓 목소리), 3개월 뒤 반응 보고 剪映 数字人 도입 결정.
- 주간 시간 예산: 촬영 4h + 생성·다듬기 5회×30분 + 댓글 매일 20분 = 주 9시간.

## 6. 성장 메커니즘
1. 검색 유입: 제목 = 시그니처 + 동네 + 카테고리 + 숫자 ｜ 훅. 본문 첫 줄에 큰 키워드, 태그 8개 이하.
2. 저장 유도: 마지막 카드는 항상 동선 카드. 본문 끝 "收藏起来到了直接用".
3. 댓글 설계: 아웃트로 카드에서 질문("想去哪一家？"). 발행 후 1시간 안에 모든 댓글 답글. 자주 나오는 질문은 다음 노트 주제로.
4. 群聊: 팔로워 1,000 넘으면 "首尔搭子群" 개설. 여행 날짜별 질문을 받고, 협찬 매장 이벤트를 여기서 먼저 공지.
5. 발행 시간: 中国时间 12:00 또는 21:00. 주말 노트는 토요일 오전 10시.
6. 첫 30일은 노출보다 형식 고정에 집중. 커버 템플릿을 절대 바꾸지 않는다.

## 7. 90일 실행 계획
### 0~2주: 세팅
- 계정 개설, 이름 首尔她地图, 소개 3줄(누구·어디·뭘 주는지), 마스코트 프로필.
- 성수·연남·홍대·마곡 촬영 1회씩. 노트 12개 선제작 후 하루 1개 발행 시작.
- 合集 5개 생성. 프로필 링크는 없음(외부 링크 금지). "私信 발송 자동응답"에 자주 묻는 질문 정리.
### 3~6주: 검색 점유
- 동네 攻略 8개 + 실용 정보 4개 + 뷰티 4개. 매주 데이터 확인: 어떤 제목이 검색 유입을 만들었는지 → 같은 구조로 반복.
- 팔로워 1,000 달성 시 蒲公英 신청(실명인증 가능한 경우).
### 7~12주: 첫 수익
- 探店 샘플 노트 5개를 들고 한국 매장에 협찬 제안. 대상: 이미 노트에 넣은 곳 + 신규 오픈 카페. 제안서 템플릿은 docs/PITCH.md.
- 제휴 가입: Olive Young Global, Klook, Trip.com, Creatrip. 링크는 私信 자동응답과 群聊에서만.
- 목표: 팔로워 5,000, 협찬 방문 2건, 群聊 200명.

## 9. KPI (주간 체크)
- 노트당 저장률 5% 이상, 팔로우 전환 1% 이상이면 형식 유지. 미달 3주 연속이면 훅·커버만 교체(팔레트는 유지).
- 검색 유입 비중 40% 이상이 목표. 아래면 제목 키워드 층 재점검.
- 댓글 응답 24시간 내 100%.

## 10. 리스크와 준수
- AI 표시: 캐릭터·TTS 사용 노트는 반드시 "AI生成" 라벨. 카드에는 이미 기본 인쇄됨.
- 외부 링크·QR·위챗 ID 본문 기재 금지. 계정 제한 사유 1위.
- 주류 콘텐츠 금지(위스키 사이트와 완전 분리). 뷰티는 효능 단정 표현 금지.
- 사진 저작권: 직접 촬영만. 매장 사진 재사용 시 출처 표기.
- 정보 정확성: places.csv의 source_url·verified_on 유지, 분기마다 재검증. 폐업 정보는 최악의 신뢰 손실.
- 개인 안전: 얼굴·집 근처·출퇴근 동선 노출 금지. 마곡 콘텐츠는 상업 지역만.
