# 중국에서 지금 뜨는 한국 여행 (2026-09 조사, 한국어 정리)

## 1. 큰 흐름 (숫자)
- 2026년 상반기 방한 외국인 1,071만 중 중국 본토 321만(약 30%)으로 1위.
- 2026년 5월 외국인 카드 소비 사상 처음 2조원 돌파, 중국인 소비 전년 대비 +214%.
- 중국 언론 표현: "한국은 경치가 아니라 '예뻐지는 것'을 판다". 2025년 외국인 미용의료 방문 200만 명(+71.9%), 그중 중국인 30.8%로 1위.
- 소비가 "扫货(쓸어 담기)"에서 "体验型生活方式(체험형 라이프스타일)"로 이동. 한국인처럼 동네 카페에 앉고, 소품샵 구경하고, 한국인의 일상을 따라 한다.
- 지방 확산: 부산 예약 +119.5%, 제주 +29%, 인천 +23%, 서울 +4.2% (중추절·국경절 기준). 경주·강릉·전주가 "느린 여행" 키워드로 뜸.
- 서울 안에서는 명동·강남 중심에서 성수·한남·연남으로 핫플이 이동했다고 중국어권 가이드가 명시.

## 3. 중국어권 가이드가 그리는 표준 4박5일
1. 1일차: 입국 → 홍대 숙소 → 홍대 걷고싶은거리·인생네컷 → 연남 저녁
2. 2일차: 경복궁 한복(오전) → 익선동/북촌 → 명동 환전·올리브영 → 남산 야경
3. 3일차: 서울숲 자전거 → 성수 팝업·카페 → 한강 라면·피크닉
4. 4일차: 도산 하우스도산·런던베이글 → 신사 가로수길 → 강남 별마당 → 찜질방
5. 5일차: 다이소·편의점 마지막 쇼핑 → 퇴세 → 출국
포인트: 3·4일차가 우리 계정의 영역. 1·5일차는 김포 이용자에게 마곡 버전으로 바꿔 줄 수 있다.

## 4. 필수 쇼핑 (2026 중국어권 리스트에서 반복되는 것)

- 올리브영: 쿠션, 립틴트, 세럼, 마스크. 당장 퇴세 되는 매장 확인
- 편의점: 한정 젤리, 바나나우유, 허니버터칩, 불닭 치즈
- 편집숍: 탬버린즈 핸드크림, 젠틀몬스터, 논픽션
- 소품: 오브젝트 문구, 인생네컷 앨범(다이소에 전용 앨범 있음)
